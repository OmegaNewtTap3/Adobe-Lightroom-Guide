## 📌 What is Lightroom?

Adobe Lightroom is a **photo editing and management ecosystem** built around non-destructive RAW processing, catalog-based organization, and cross-device sync. It comes in two flavors:

| Version               | Best for                                                        |
| ---------------------- | ----------------------------------------------------------------- |
| **Lightroom Classic** | Desktop-first, folder-based workflow, deep editing tools, local storage |
| **Lightroom (CC)**    | Cloud-native, simplified interface, sync across desktop/mobile/web |

## ✨ Key Features

| Feature                  | Description                                              |
| -------------------------- | ------------------------------------------------------------ |
| Non-destructive editing  | Every edit is stored as instructions, original stays untouched |
| Catalog system            | Central database to organize, tag, and search thousands of photos |
| RAW processing            | Full Camera Raw engine with lens/profile corrections       |
| AI Masking                | Select sky, subject, or background automatically           |
| Presets & Profiles        | One-click looks, shareable and customizable                |
| Cloud sync (CC)           | Edit on desktop, continue on phone or web                  |
| Tethered shooting (Classic) | Import photos directly from camera during a shoot         |
